# 💰 **Проект «Прогнозирование оттока клиентов банка»**

Банк “ФинПрогресс” ежегодно теряет 16 % клиентов (на выборке кредитных карт — 1600 из 10 000), 
что выливается в 19,2 млн рублей финансовых потерь. Текущие реактивные меры по удержанию неэффективны 
(конверсия 15–20 %), поэтому критически важно перейти к проактивной стратегии: нужен точный прогноз 
оттока по каждому клиенту, чтобы вовремя предлагать релевантные меры удержания.

Бинарная классификация даёт интерпретируемый результат в формате «да или нет» (1 или 0), 
который легко перевести в конкретные действия: для «1» — запустить удержание, для «0» — не тратить ресурсы банка.

Ключевые метрики успеха модели:

- **Recall ≥ 0,8**. Модель должна находить не менее 80% реально уходящих клиентов;
- **F1-score ≥ 0,7**. Сохранение баланса между точностью прогноза и полнотой охвата;
- **ROC-AUC ≥ 0,85**. Высокая способность алгоритма верно ранжировать клиентов по уровню риска.

**Итоговый продукт для бизнеса** — интерактивный дашборд в DataLens для мониторинга ситуации в реальном времени. 

🎯 **Цель проекта** - построить модель бинарной классификации, которая спрогнозирует вероятность оттока 
каждого клиента в следующем месяце.

📋 **Задачи проекта:**

1. Загрузить данные и ознакомиться с ними;
2. Провести исследовательский анализ данных;
3. Подготовить признаки для обучения алгоритмов;
4. Выполнить анализ корреляции признаков;
5. Обучить модели и сравнить метрики;
6. Провести анализ важности признаков;
7. Получить финальные предсказания;
8. Сформулировать выводы и рекомендации для бизнеса;
9. Создать DDL-схему в ClickHouse с признаками, которые влияют на отток клиентов;
10. Загрузить СSV-файл с моделью прогнозирования в хранилище s3 с помощью Spark-скрипта;
11. Создать с помощью DAG-скрипта оркестрацию данных в Apache AirFlow;
12. Построить интерактивный дашборд для мониторинга ситуации в реальном времени.

### 🏆 **Результаты**

Выбрана модель RandomForestClassifier (порог 0,4). Цели по F1‑score (0.767) и ROC‑AUC (0.945) достигнуты. 
Recall (71.2%) ниже целевого (80%) из‑за компромисса с Precision: снижение порога для роста Recall 
кратно увеличит ложные срабатывания и маркетинговые затраты без пропорционального роста эффекта.

Статистический анализ показал чёткое разделение клиентской базы:

- 86,1 % клиентов (2506 чел.) имеют низкую вероятность оттока (< 0,4) — эта группа не требует активных мер удержания;
- 2,2 % клиентов (63 чел.) находятся в пограничной зоне (0,4–0,5) — их целесообразно использовать для тестирования мягких предложений или усиленного мониторинга динамики поведения;
- 11,7 % клиентов (341 чел.) попадают в зону высокого риска (> 0,5) — это приоритетная аудитория для акций удержания.

Выбраны признаки, которые влияют на вероятность оттока клиентов: 
- `customer_satisfaction_score`- оценка удовлетворённости клиента сервисом;
- `credit_limit_change_yoy` - изменение кредитного лимита за год;
- `credit_limit` - установленный кредитный лимит (в долларах).

### 💡 **Рекомендации**

1. **Триггерная реакция на низкую удовлетворённость.**

При любой негативной оценке или отзыве автоматически ставить статус «Критический риск» и 
передавать тикет персональному менеджеру — даже если прогноз модели ниже порога.

KPI: время реакции на жалобу — не более 2 часов (сейчас 24–48 ч).

2. **Проактивная коммуникация при изменении лимита.**

За 3 дня до снижения лимита отправлять уведомление с объяснением причины и вариантом сохранения 
лимита (например, через 3 покупки от X руб.).

KPI: доля клиентов, сохранивших лимит после уведомления, — более 50 %.

3. **Сегментация базы для акций по прогнозу оттока.**

Направлять маркетинговые коммуникации только на клиентов со средним и высоким риском (порог ≥ 0.4), 
исключив 86 % низкорисковой аудитории.

KPI: рост ROI кампаний — не менее 20 % за счёт исключения нецелевых клиентов.

4. **Мониторинг падения транзакций как ранний сигнал.**

Ежемесячно выявлять клиентов с падением оборотов более чем на 30 % к прошлому кварталу и предлагать 
им мягкие стимулы (повышенный кэшбэк).

KPI: доля клиентов, восстановивших обороты после предложения, — не менее 15 %.
